# MazeBot导航系统 - 迷宫匹配模块

## 概述

本模块实现了MazeBot项目的迷宫匹配功能，通过雷达数据进行墙壁检测和拟合，建立4×4网格迷宫模型。

## 功能特性

### 1. 迷宫匹配
- **网格建模**：4×4网格迷宫，每个格子70cm×70cm
- **墙壁检测**：基于雷达点云的墙壁检测和拟合
- **置信度评估**：为每个检测到的墙壁提供置信度评分
- **增量更新**：只更新新发现的墙壁，避免重复计算

### 2. 数据处理
- **点云聚类**：按方向（北、东、南、西）聚类雷达点云
- **线段拟合**：使用最小二乘法拟合直线段
- **噪声过滤**：基于质量阈值过滤低质量数据点
- **坐标转换**：极坐标到笛卡尔坐标的转换

### 3. 可视化系统
- **实时显示**：网格地图、雷达点云、机器人轨迹
- **置信度热力图**：显示墙壁检测的置信度分布
- **动画支持**：机器人运动轨迹动画
- **数据导出**：保存迷宫地图为图像文件

## 核心类

### MazeMapper
迷宫匹配主控制器，负责：
- 雷达数据处理和墙壁拟合
- 网格地图更新
- 置信度计算
- 边界墙壁初始化

### MazeMap
迷宫地图数据结构，包含：
- 水平墙壁数组（walls_h）
- 垂直墙壁数组（walls_v）
- 雷达点云数据
- 机器人轨迹

### WallSegment
墙壁线段类，包含：
- 起始和结束位置
- 置信度评分
- 观测历史记录
- 线段长度

### MazeVisualizer
可视化系统，提供：
- 网格地图显示
- 雷达点云可视化
- 置信度热力图
- 动画功能

### MazeInterface
与主系统接口，提供：
- 数据队列管理
- 实时状态监控
- 配置管理
- 统计信息

## 使用方法

### 基本使用

```python
from Navigation import MazeInterface, create_maze_interface

# 创建迷宫接口
entrance_pos = (0, 0)
exit_pos = (4, 4)
maze_interface = create_maze_interface(entrance_pos, exit_pos)

# 启动接口
maze_interface.start()

# 添加雷达数据
lidar_data = [(0, 0.5, 10), (90, 0.3, 8), (180, 0.7, 12), (270, 0.4, 9)]
maze_interface.add_lidar_data(lidar_data)

# 添加里程计数据
maze_interface.add_odom_data(x=1.0, y=1.0, heading=0.0)

# 可视化当前状态
maze_interface.visualize_current_state()

# 停止接口
maze_interface.stop()
```

### 高级配置

```python
config = {
    'min_points_for_fitting': 3,      # 拟合所需最少点数
    'confidence_threshold': 0.3,      # 置信度阈值
    'direction_tolerance': 22.5,      # 方向容差（度）
    'max_lidar_points': 1000,         # 最大雷达点数
    'max_trajectory_points': 100,     # 最大轨迹点数
    'update_interval': 0.1,           # 更新间隔（秒）
    'visualization_enabled': True,    # 启用可视化
    'debug_mode': False               # 调试模式
}

maze_interface = create_maze_interface(entrance_pos, exit_pos, config)
```

## 算法原理

### 1. 坐标系定义
- **格点中心**：(0,0), (1,0), (2,0), ..., (4,4) - 机器人可以到达的位置
- **墙壁位置**：(0.5,0), (1.5,0), ..., (0,0.5), (0,1.5), ... - 墙壁位于格点之间

### 2. 墙壁检测流程
1. **数据预处理**：过滤低质量雷达点
2. **坐标转换**：极坐标转笛卡尔坐标
3. **方向聚类**：按四个主要方向聚类点云
4. **线段拟合**：最小二乘法拟合直线
5. **置信度计算**：基于点数和拟合质量
6. **网格映射**：将拟合结果映射到网格结构

### 3. 置信度计算
```
置信度 = (点数贡献 + 拟合质量贡献) / 2
点数贡献 = min(1.0, 点数 / 10.0)
拟合质量贡献 = max(0.0, 1.0 - 标准差 / 0.1)
```

## 注意事项

1. **数据质量**：雷达数据质量直接影响墙壁检测精度
2. **噪声处理**：系统对噪声有一定的鲁棒性，但极端噪声可能影响性能
3. **内存管理**：系统会自动清理旧数据，避免内存泄漏
4. **线程安全**：接口类支持多线程环境下的安全使用

## 故障排除

### 常见问题

1. **墙壁检测不准确**
   - 检查雷达数据质量
   - 调整置信度阈值
   - 增加观测次数

2. **性能问题**
   - 减少雷达点数
   - 增加更新间隔
   - 启用数据清理

3. **可视化问题**
   - 检查matplotlib版本
   - 确认显示环境
   - 启用调试模式
