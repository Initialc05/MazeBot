2. **实机测试**：连接真实硬件进行测试

- ✅ 依赖库已安装：`numpy`, `matplotlib`

## 实机测试

### 1. 硬件连接检查

#### 1.1 串口配置
在 `maze_test_integration.py` 中检查串口配置：
```python
# 串口配置
USE_BLUETOOTH_MODE = True
if USE_BLUETOOTH_MODE:
    SERIAL_PORT = 'COM18'  # 蓝牙串口（根据实际情况修改）
    BAUD_RATE = 921600     # 蓝牙波特率
else:
    SERIAL_PORT = 'COM7'   # USB串口
    BAUD_RATE = 115200     # USB串口波特率
```

#### 1.2 迷宫配置
```python
# 迷宫配置
ENTRANCE_POS = (0, 0)  # 入口位置
EXIT_POS = (4, 4)      # 出口位置
```

### 2. 运行实机测试

#### 2.1 启动测试
```bash
cd MazeBot/Navigation
python maze_test_integration.py
```

#### 2.2 测试界面
测试程序会显示4个窗口：
- **左上**：原始雷达数据
- **右上**：迷宫地图
- **左下**：水平墙壁置信度热力图
- **右下**：垂直墙壁置信度热力图

#### 2.3 控制按钮
- **保存地图**：点击保存当前迷宫地图为PNG文件

### 3. 测试步骤

#### 3.1 初始检查
1. 启动程序后，检查串口连接状态
2. 确认数据包接收正常
3. 检查机器人位置显示

#### 3.2 墙壁检测测试
1. 将机器人放置在迷宫入口
2. 观察雷达数据是否正常显示
3. 检查墙壁检测结果
4. 验证置信度计算

#### 3.3 移动测试
1. 手动控制机器人移动
2. 观察轨迹显示
3. 检查墙壁检测的连续性
4. 验证地图更新

#### 3.4 边界测试
1. 将机器人移动到迷宫边界
2. 检查边界墙壁检测
3. 验证坐标转换正确性

### 5. 故障排除

#### 5.1 串口连接问题
```
❌ 串口连接失败
解决方案：
1. 检查串口号是否正确
2. 检查蓝牙连接状态
3. 重启蓝牙模块
4. 检查波特率设置
```

#### 5.2 数据接收问题
```
❌ 没有接收到数据包
解决方案：
1. 检查下位机程序是否运行
2. 检查数据包格式
3. 检查校验和
4. 检查同步标记
```

#### 5.3 墙壁检测问题
```
❌ 墙壁检测不准确
解决方案：
1. 调整置信度阈值
2. 检查雷达数据质量
3. 增加观测次数
4. 调整拟合参数
```

#### 5.4 可视化问题
```
❌ 图形显示异常
解决方案：
1. 检查matplotlib版本
2. 检查显示环境
3. 启用调试模式
4. 检查内存使用
```
