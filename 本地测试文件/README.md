# 本地测试文件

> 不上传到 GitHub。用来放调试脚本、采集数据、工作日志、临时草稿等。

## 目录结构

| 目录 | 用途 |
|---|---|
| `01_工作日志/` | 每天的进展记录、决策、遇到的问题、解决方案 |
| `02_采集数据/` | 真车采集的原始数据（雷达截图、F/B/L/R 测量记录、saved_maps 副本） |
| `03_算法原型/` | 导航算法的 Python 原型（Flood-Fill 仿真、贴墙走脚本等） |
| `04_临时脚本/` | 临时验证想法的小脚本，用完即丢 |
| `05_参考截图/` | 截图、照片、笔记图片等 |

## 使用约定

- **每次有进展，更新 `01_工作日志/` 下当天的日志文件**
- 文件名用日期前缀：`2026-05-13_xxx.md`
- 采集数据文件名要自解释：`F50_5次_2026-05-13.txt`，不要 `data1.txt`
- 任何能让"明天的自己一秒看懂"的命名都行

## 与主仓库（MazeBot-5.0）的关系

- 主仓库在 `..\MazeBot-5.0\`，那是要上 GitHub 的代码
- 本目录在主仓库**外面**，git 看不到这里
- 算法原型成熟后，再迁移到主仓库的 `Host/` 或新建子目录
