# Flood-Fill 迷宫仿真（阶段 1 原型）

MazeBot 导航算法的纯软件原型。**不依赖真车**——目的是验证 Flood-Fill 在我们的迷宫拓扑上能稳定到终点，并对比"老师给图 vs 不给图"两种分支。

## 怎么跑

```bash
cd Host/navigation/flood_fill_sim

# 分支 A：老师不给图，从零探索（默认）
python visualize.py
python visualize.py z_island_5x5
python visualize.py trap_5x5

# 分支 B：老师给完整图，直接冲刺（跳过探索）
python visualize.py z_island_5x5 --prior
python visualize.py trap_5x5 --prior

# 分支 B'：图不完整（缺一半内墙），算法会用感知补
python visualize.py z_island_5x5 --prior=partial
```

依赖：`numpy` + `matplotlib`，已经装过。

## 两种分支什么意思

### A. 老师不给图（`--no-prior`，默认）

机器人从空白信念出发：**只知道有外墙**，里面什么都不知道。每走到一格：
1. **感知**当前格的 4 面墙（实车上对应雷达扫一圈）
2. **重算**距离场（Flood-Fill）
3. 选邻居中距离最小的方向走

走到终点之后，把学到的地图**冲刺重跑一遍**——这是"探索 + 冲刺"两遍走法。比赛时计时通常算冲刺那遍。

### B. 老师给图（`--prior`）

直接把老师的图录入成 belief，**跳过探索阶段**，一开始就冲刺。代码在 `Simulator.run_direct()`。

### B'. 图不完整（`--prior=partial`）

老师给的图缺墙或多墙——这是更现实的情况。机器人**仍然每步感知**，把感知到的墙加进 belief。如果图错了，Flood-Fill 自动重规划。**这是最稳健的模式**。

## 仿真结果对比

```
迷宫               分支 A(从零)   分支 B(完整图)
z_island_5x5       6 步 / 2 转弯  6 步 / 2 转弯
trap_5x5           8 步 / 1 转弯  8 步 / 1 转弯
corridor_5x5       24 步 / 9 转弯 24 步 / 9 转弯
```

**步数一样**——因为 Flood-Fill 的乐观假设让"无图"也能走最短路。**但实战中差别很大**：
- A 模式：机器人**真的要走**那些格子才能学到墙。每走一格要感知、决策、移动——时间成本不为零
- B 模式：第 0 秒就有完整地图，**省掉整个探索**

仿真没建模"探索本身花的时间"，所以两个分支表面上一样。真车上 B 至少快一倍。

## 录入老师的图

`maze.py` 里有 `build_from_ascii()`，可以用 ASCII 画图直接录入：

```python
from maze import build_from_ascii

maze, start, goal = build_from_ascii("""
+--+--+--+--+--+
|              |
+  +  +  +  +  +
|     |     | G|
+  +--+--+  +--+
|        |     |
+  +--+--+  +  +
|     |     |  |
+  +  +  +  +  +
|S             |
+--+--+--+--+--+
""")
```

规则：
- `+` 是格子角（结构占位）
- `--` 之间的两格 = 水平墙存在；两个空格 = 没墙
- `|` 之间 = 竖墙存在；空格 = 没墙
- 格子内部写 `S`/`G` 标起点/终点
- **底部**那行 ASCII 是迷宫的 row 0（坐标系 Y 轴向上）

赛前 5 分钟对着老师给的图照着描一份，存进 `maze.py` 即可。

## 算法关键点（一段话总结）

> 从终点开始 BFS 给每格标"距离"。机器人每次走到距离更小的邻居。每走一格，雷达感知本格四面墙，把新信息加入信念地图，重算距离场。**未知 = 假设无墙**（乐观）。这保证最多 N² 步必到终点；简单迷宫上几乎走最短路径。

转弯惩罚 = 2：两条等长路径中偏好直行——竞速时直行远快于"走停转走停"。

## 当前版本刻意没做什么

- 没有连续坐标——纯格子离散世界
- 没有雷达噪声/形变——`sense()` 直接读 truth，将来阶段 2 替换成"从雷达点云反推墙"
- 没有"贴墙走"运动原语——格子之间是瞬移，将来阶段 2 处理
- 没有未探索格的代价奖励——分支 A 偶尔会探索冗余格子，赛前用分支 B 就好
