# Design and Build 2025 - 自主迷宫导航机器人项目介绍

## 第一部分：整体项目介绍

### 项目概述
- **项目名称**：Design and Build 2025 - Autonomous Mobile Robot for Maze Mapping and Navigation with 2D LiDAR
- **核心目标**：设计并构建一个配备2D激光雷达的自主移动机器人
- **主要功能**：
  - 实时环境建图
  - 自主迷宫探索
  - 出口点识别
  - 返回起点导航

### 硬件组件
- **STM32F446RE微控制器**：实时传感器处理、电机控制、通信管理
- **SLAMTEC RPLIDAR C1**：2D激光雷达，360度环境感知
- **MPU6500 IMU**：6轴惯性测量单元，姿态跟踪
- **520编码器直流电机**：精确运动控制，里程计反馈
- **AT8236电机驱动器**：电机控制接口
- **HC-04蓝牙模块**：无线通信

## 第二部分：下位机部分介绍

### 固件架构
- **开发框架**：基于Arduino的STM32固件开发
- **实时操作系统**：FreeRTOS多任务调度
- **任务分配**：
  - IMU900任务（500Hz）：高精度里程计更新
  - 雷达任务（500Hz）：LiDAR数据处理
  - 控制任务（1kHz）：蓝牙指令响应
  - 电机控制任务（200Hz）：PID控制执行

### 传感器接口

#### LiDAR数据处理
- **传感器型号**：SLAMTEC RPLIDAR C1
- **通信协议**：460800波特率串口通信
- **数据格式**：5字节数据包（角度、距离、质量）
- **处理流程**：
  ```cpp
  // 数据包解析
  struct rplidar_response_measurement_node_t {
      uint8_t  sync_quality;      // 同步位+质量
      uint16_t angle_q6_checkbit; // 角度Q6格式
      uint16_t distance_q2;       // 距离Q2格式
  };
  ```

#### IMU姿态估计
- **传感器型号**：MPU6500 6轴IMU
- **数据融合**：加速度计+陀螺仪+磁力计
- **输出数据**：欧拉角（X、Y、Z轴）、位移（X、Y、Z）
- **更新频率**：250Hz

#### 编码器里程计
- **编码器规格**：13线×30减速比 = 390脉冲/圈
- **轮径参数**：65mm
- **轮距参数**：100mm
- **里程计算法**：差速轮运动学模型

### 电机控制

#### PID控制算法
- **航向控制PID**：保持机器人朝向
- **速度差控制PID**：左右轮速度同步
- **转向控制PID**：精确角度控制

#### 运动控制模式
- **精准移动**：基于里程计的距离控制
- **精准转向**：基于IMU的角度控制
- **状态机管理**：空闲→运行→到达

### 通信协议

#### 蓝牙数据包格式
- **雷达数据包**（18字节）：
  ```
  包头(2) + 角度(4) + 距离(2) + 质量(1) + 里程计(8) + 校验(1)
  ```

- **里程计数据包**（11字节）：
  ```
  包头(2) + X坐标(2) + Y坐标(2) + 角度(4) + 校验(1)
  ```

#### 数据流管理
- **实时传输**：250Hz IMU数据 + 雷达扫描数据
- **数据融合**：时间戳对齐，确保数据一致性
- **错误处理**：校验和验证，异常数据过滤
